今日事 · 隐私说明

更新日期：2026 年 9 月 28 日

今日事是个人自用的每日备忘应用（Windows 和 iPhone）。本说明介绍应用会访问哪些数据，以及这些数据如何处理。

应用访问的数据

  • Google 日历和 Google Tasks：在用户通过 Google 授权后，读取、新建、修改和删除用户的日程与待办，用于在应用和小组件中显示，并在电脑与手机之间同步。
  • Google 账号邮箱：仅用于在设置中显示当前登录的账号。
  • iPhone「日历」和「提醒事项」（iPhone 版）：在用户允许后读取和修改，用于显示，并按用户的选择与 Google Tasks 同步。
  • iCloud 日历（Windows 版，可选）：用户填写 Apple ID 和 App 专用密码后读取和新建日程。

数据如何处理

  • 所有数据只在用户的设备与 Google、Apple 的服务器之间直接传输，不经过任何第三方服务器。
  • 开发者不收集、不存储、不出售、不分享任何用户数据，应用不包含任何统计、广告或追踪代码。
  • 授权令牌和缓存只保存在用户自己的设备上：Windows 版使用系统 DPAPI 加密保存，iPhone 版保存在应用自身的存储空间中。

Google API 用户数据政策

今日事对从 Google API 获得的信息的使用和转移，遵守 Google API Services User Data Policy，包括其中的 Limited Use（有限使用）要求。

撤销授权和删除数据

  • 随时可以在 Google 账号的第三方访问设置 中移除「今日事」的访问权限，或在应用设置中退出登录。
  • 删除应用（iPhone）或删除 %APPDATA%\DailyMemo 文件夹（Windows）即可清除本机保存的全部数据；Google、Apple 账号中的日程和待办不受影响。
