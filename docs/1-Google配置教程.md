# Google 配置教程（一次性，约 5 分钟）

「今日事」直接调用 Google 官方接口读写你的日历和待办。Google 要求每个应用有自己的「OAuth 客户端」，所以需要在 Google Cloud 里给自己建一个——**完全免费，只有你自己用**。

> 在中国大陆需要先打开网络代理，才能访问下面的网址和登录 Google。

## 第 1 步：创建项目

1. 打开 <https://console.cloud.google.com/> ，用你的 Google 账号登录。
2. 顶部选择项目的下拉框 → **新建项目**，名字随意（例如 `今日事`），创建后切换到这个项目。

## 第 2 步：启用两个 API

1. 左侧菜单 → **API 和服务 → 库**。
2. 搜索 **Google Calendar API** → 启用。
3. 再搜索 **Google Tasks API** → 启用。

## 第 3 步：配置「OAuth 同意屏幕」

1. 左侧菜单 → **Google Auth Platform**（旧版界面叫「OAuth 同意屏幕」）→ **开始**。
2. 应用名称填 `今日事`，用户支持电子邮件选你自己的邮箱。
   **不要上传应用徽标**：上传徽标后，应用发布时需要 Google 审核（验证）。应用首页、隐私权政策、服务条款、已获授权的网域都留空即可。
   页面顶部的「$300 赠金 / 免费开始使用」不用管——日历和 Tasks 接口免费，不需要绑定信用卡。
3. 目标对象（用户类型）选 **外部**。
4. 联系信息填你的邮箱，同意条款，创建。
5. 进入 **目标对象（Audience）**，发布状态处点 **发布应用 → 确认**，变成「正式版 / In production」。

> 为什么要「发布」：保持「测试」状态的话，Google 会让登录 **7 天后自动失效**。发布后不需要 Google 审核，只是登录时会提示「Google 尚未验证此应用」——这是你自己建的应用，点 **高级 → 转到今日事（不安全）** 继续即可。

## 第 4 步：创建电脑用的客户端（桌面应用）

1. **Google Auth Platform → 客户端（Clients）→ 创建客户端**。
2. 应用类型选 **桌面应用**，名称填 `今日事 Windows`，创建。
3. 在弹窗里点 **下载 JSON**（文件名类似 `client_secret_xxxx.json`）。
4. 打开电脑上的今日事 → **设置 → Google 账号 → 导入 JSON 文件…** 选择它，再点 **登录 Google**。
5. 浏览器里选择账号，看到「Google 尚未验证此应用」时点 **高级 → 转到今日事**，然后**勾选全部权限**并继续。看到「已连接 Google 账号」就可以关掉浏览器页面了。

## 第 5 步：创建手机用的客户端（iOS）

1. 同一个项目里 **客户端 → 创建客户端**，应用类型选 **iOS**。
2. **软件包 ID（Bundle ID）** 填 `com.dailymemo.app`。
   如果你用的签名工具改了 Bundle ID（例如 Sideloadly 会加后缀），填改后的那个——在 iPhone 版「设置 → Google 账号 → iOS 客户端 ID」页面里能看到当前的 Bundle ID。
3. 创建后复制 **客户端 ID**（`xxxxx.apps.googleusercontent.com`，iOS 客户端没有密钥）。
4. iPhone 打开今日事 → **设置 → Google 账号 → iOS 客户端 ID**，粘贴，返回后点 **登录 Google**。

## 常见问题

| 现象 | 解决 |
|---|---|
| 登录后提示「没有启用 Calendar API / Tasks API」 | 回到第 2 步确认两个 API 都已启用（要在同一个项目里） |
| 「Google 授权已失效，请重新登录」 | 多半是没做第 3 步第 5 条的「发布应用」，发布后重新登录一次 |
| 浏览器显示 `access_denied` / 「已被 Google 阻止」 | 同意屏幕还在「测试」状态且你的账号不在测试用户里 → 发布应用，或把自己加为测试用户 |
| 电脑版提示网络连接失败 | 打开代理；如果代理软件没有设置系统代理，在「设置 → 网络代理」里填它的 HTTP 端口，例如 `127.0.0.1:7890` |
| 登录时没有勾选全部权限 | 到 <https://myaccount.google.com/permissions> 移除「今日事」，再重新登录并全部勾选 |

## 这些权限用来做什么

| 权限 | 用途 |
|---|---|
| 查看你的日历（calendar.readonly） | 列出你的日历，显示日程 |
| 修改日历中的活动（calendar.events） | 在今日事里新建、修改、删除日程 |
| 管理你的任务（tasks） | 读写 Google Tasks，也是电脑和 iPhone 提醒事项同步的中转站 |
| 邮箱地址（email） | 在设置里显示你登录的是哪个账号 |
